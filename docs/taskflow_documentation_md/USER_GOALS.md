# User Goals — TaskFlow

## Primary User

One authenticated user managing their own tasks and projects.

No team collaboration or roles.

---

## Goal 1 — Capture a Task Quickly

### User intent
“I remembered something I need to do. I want to save it before I forget.”

### Desired outcome
- create a task in seconds,
- title is enough,
- optional details can be added later.

### Product support
- `+ New Task` in top bar,
- quick task form,
- sensible defaults,
- keyboard-friendly interaction.

---

## Goal 2 — Know What to Work on Next

### User intent
“I have many tasks and need to understand what matters now.”

### Desired outcome
User can immediately identify:

- overdue tasks,
- high-priority tasks,
- tasks due soon,
- tasks already in progress.

### Product support
- priority badges,
- due dates,
- overdue state,
- dashboard summary,
- filtering.

---

## Goal 3 — Update Progress Without Extra Form Work

### User intent
“I finished or started a task and only want to update its status.”

### Desired outcome
Move a task visually without opening an edit form.

### Product support
- Kanban drag-and-drop,
- persistent ordering,
- Sonner feedback,
- activity logging.

---

## Goal 4 — Keep Different Work Organized

### User intent
“I work on multiple projects and don't want all tasks mixed together.”

### Desired outcome
Tasks can be grouped and filtered by project.

### Product support
- projects,
- project color,
- project filter,
- project detail,
- project-level progress.

---

## Goal 5 — Break Big Work Into Smaller Steps

### User intent
“A task is too large to complete in one action.”

### Desired outcome
Create a checklist/subtasks without needing a separate project.

### Product support
- subtasks,
- completion progress,
- reorder subtasks,
- compact progress on card/detail.

---

## Goal 6 — Find an Old or Specific Task

### User intent
“I know I created a task before but cannot remember where it is.”

### Desired outcome
Find it quickly.

### Product support
- global search,
- task search,
- status/project/tag filters,
- sorting.

---

## Goal 7 — Understand Deadlines Visually

### User intent
“I want to see my workload by date.”

### Desired outcome
View tasks in a calendar.

### Product support
- calendar view,
- due date indicators,
- overdue styling,
- date-based filters.

---

## Goal 8 — Review Personal Progress

### User intent
“I want to know whether I am actually completing my work.”

### Desired outcome
See simple productivity metrics.

### Product support
- completion trends,
- completed task count,
- overdue trends,
- project distribution,
- priority distribution.

---

## Goal 9 — Use the App Comfortably Every Day

### User intent
“I want a tool that feels calm and fast, not like a complex enterprise system.”

### Desired outcome
Consistent, low-friction experience.

### Product support
- sage green visual system,
- Poppins,
- top navigation,
- subtle borders/shadows,
- predictable interactions,
- responsive layout,
- empty/loading/error states.

---

## Product Success Signals

The product is succeeding if:

- most tasks can be created without leaving the current workflow,
- status changes are commonly performed through drag-and-drop,
- the user can find any active task quickly,
- overdue work is difficult to miss,
- the board remains usable even with many tasks,
- the interface still feels simple after adding projects, filters, and reports.
